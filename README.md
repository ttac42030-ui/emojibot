# Emoji Nickname Bot

Telegram-бот: пользователь присылает ник → выбирает расцветку кнопкой →
получает набор custom emoji со своим ником. Первый эмодзи бесплатно,
каждый следующий — 2⭐ Telegram Stars (можно поменять цену в `.env`).

Все картинки рисуются программно (Pillow, градиент + текст) — без
сторонних AI-сервисов и без использования чужих стикер-паков.

## Важно про "анимированные"

В этой версии эмодзи — **статичные** (PNG, 100x100), это самый
надёжный и быстрый вариант через обычный Bot API
(`createNewStickerSet` / `addStickerToSet`, `sticker_type=custom_emoji`).

Настоящая анимация потребует либо:
- **TGS** (Lottie/векторная анимация, сложнее генерировать программно), либо
- **WEBM-видео** (проще: можно анимировать градиент/текст через Pillow-кадры
  + сборку в webm через ffmpeg).

Если нужно — могу добавить video-стикеры (WEBM) отдельным шагом, это
не переписывает архитектуру, только генератор.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

`.env` уже содержит ваш токен бота:

```env
BOT_TOKEN=...
EXTRA_EMOJI_STARS_PRICE=2
```

## Запуск локально (если есть ПК/VPS)

```bash
python bot.py
```

Без `WEBHOOK_URL` в `.env` бот сам пойдёт в режим long polling —
процесс должен работать постоянно (VPS, systemd, screen/tmux, Docker).

## Запуск бесплатно с телефона (Render.com, без карты)

Если своего сервера нет — бот умеет работать в режиме webhook: сам
поднимает HTTP-сервер, а Telegram присылает ему обновления. Это как
раз то, что нужно для бесплатного тарифа Render.

Всё делается из браузера на телефоне:

1. **GitHub** — зайдите на github.com, зарегистрируйтесь (только email,
   без карты). Создайте новый репозиторий (New repository), например
   `emojibot`. На странице репозитория нажмите "Add file → Upload
   files" и загрузите туда все файлы из этого проекта (можно раз-
   архивировать zip прямо в приложении-файловом менеджере телефона
   и выбрать файлы для загрузки).

2. **Render** — зайдите на render.com, "Get Started" → войдите через
   GitHub (тоже без карты для бесплатного плана). Нажмите
   "New +" → "Web Service", выберите ваш репозиторий `emojibot`.

3. В настройках сервиса укажите:
   - **Environment**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python bot.py`
   - **Plan**: Free

4. В разделе **Environment Variables** добавьте:
   - `BOT_TOKEN` — ваш токен
   - `EXTRA_EMOJI_STARS_PRICE` — `2`
   - `WEBHOOK_URL` — URL вашего сервиса вида
     `https://emojibot-xxxx.onrender.com` (Render покажет его сразу
     после создания сервиса — можно сохранить деплой, посмотреть URL
     и вписать переменную вторым деплоем).

5. Нажмите **Deploy**. Через пару минут бот должен ответить на
   `/start` в Telegram.

**Особенность бесплатного тарифа Render:** если ботом никто не
пользуется 15 минут, сервис "засыпает", и следующее сообщение может
обработаться с задержкой ~30-50 секунд, пока он проснётся — это
нормально для бесплатного плана, не баг.

## Структура

- `bot.py` — хендлеры, FSM, создание стикер-сета, оплата Stars.
- `generator.py` — рисование эмодзи (Pillow) + список стилей.
- `storage.py` — простое хранилище пользователей в `db.json`.
- `fonts/Poppins-Bold.ttf` — шрифт для текста на эмодзи.

## Как добавить/поменять расцветки

Список стилей — в `generator.py`, константа `STYLES`. Формат:

```python
Style("key", "🎨 Название на кнопке", "#цвет1", "#цвет2", text_color="#цвет_текста")
```

## Ограничения Telegram, о которых стоит помнить

- Имя стикер-сета должно быть уникальным глобально — если у двух
  пользователей одинаковый ник, имя набора всё равно не совпадёт
  (в него подмешивается `user_id`), но само имя может быть занято
  сторонним пакетом — в этом случае бот попросит попробовать снова.
- Отправлять/использовать custom emoji в сообщениях многие клиенты
  дают полноценно только пользователям с Telegram Premium — это
  ограничение самого Telegram, не бота.
- Цена в Stars (`amount=2`) — это именно 2 звезды, не рубли/центы.
